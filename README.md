# 실행 방법(How to Use)

## 1. 프로젝트 가져오기(Clone)

<> Code ▼을 누르고 **Download ZIP** 또는 아래의 명령을 **명령 프롬프트**에서 입력합니다.

``` sh
git clone https://github.com/NewLandTV/SheetPython.git
```

## 2. 가상 환경 설정(Python venv)

아래의 명령은 Python 3.11 가상 환경을 만들면서 코드 실행에 필요한 모듈을 설치합니다.

``` sh
py -3.11 -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 3. 코드 실행(Run)

악보를 불러와서 보표만 추출합니다.

``` sh
python SheetMusic.py
```
